# Cas Vériane

Comprends le besoin du client, propose une solution et construis une démonstration avec ton agent IA. Le cas et les données sont fictifs.

## Commencer

```bash
git clone https://github.com/kevin-courbet/veriane-candidat.git
cd veriane-candidat
```

Ouvre **[index.html](index.html)** depuis ton clone pour explorer le bureau interactif. Aucune installation ni serveur nécessaires. **[dossier.html](dossier.html)** propose une lecture linéaire et imprimable.

Ton agent peut lire les documents et la note **[ENVIRONNEMENT-TECHNIQUE.md](ENVIRONNEMENT-TECHNIQUE.md)** pour comprendre les systèmes et interfaces du client.

## Déroulement

Lis le dossier avec ton agent. Pose tes questions à l'intervieweur, qui joue les interlocuteurs du client, puis transmets les réponses à ton agent. Signale les hypothèses et les informations manquantes.

Conviens du périmètre avec l'intervieweur avant de coder. Construis et vérifie une démonstration locale ; les services distants peuvent être simulés. Tu dois pouvoir expliquer tes choix et le code produit.

## À remettre

- **PROPOSAL.md** : besoin, processus actuel et cible, choix argumentés, hypothèses et questions ouvertes.
- Le **code** et les **instructions pour le lancer**.
- Les **vérifications réalisées**, leurs résultats et leurs limites.
